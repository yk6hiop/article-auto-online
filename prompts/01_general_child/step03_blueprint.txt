# 出典: 「引用・参考文献・出典の完全ガイド」

## Section 1: 帰属表示の語彙集（厳格な用語定義）
知的生産活動において、以下の用語をその定義と目的に従って正確に使い分けること。

| 用語 | 定義 | 目的・用法 | 許諾の要否 |
| :--- | :--- | :--- | :--- |
| **引用 (In'yō)** | 他者の著作物を、報道、批評、研究等の正当な目的で、自身の著作物内に取り込む行為。 | 自説の補強、反論の提示、具体例の紹介。 | 不要（著作権法第32条の要件を満たす場合） |
| **出典 (Shutten)** | 引用した情報の出所（情報源）。 | 引用箇所の典拠を明示し、読者による検証を可能にする。 | (引用に伴う義務) |
| **参考文献 (Sankō Bunken)** | 著作物の執筆過程で参考にした全ての資料。 | 執筆の背景となった知的貢献全体への敬意を示し、さらなる調査の手がかりを提供する。 | (リスト作成自体は不要) |
| **参照 (Sanshō)** | 他の資料（特に図表など）と照らし合わせること。 | 読者を特定の情報（図、表、データなど）へ誘導する。 | 不要 |
| **転載 (Tensai)** | 他者の著作物の大部分または全部を複製し、再公表する行為。 | 原著作物を広く紹介・共有する。 | 原則として必要 |

## Section 2 & 3: 法的・倫理的コンプライアンス・チェックリスト
他者の著作物を「引用」する際は、以下の**全要件**を満たしているか厳密に検証すること。一つでも欠ければ違法な「無断転載」または倫理的に「剽窃」と見なされる。

| 要件 | 中核的要請 | 実践的実装 |
| :--- | :--- | :--- |
| **1. 公表された著作物** | 著作権者が公に発表したものであること。 | 未公開の書簡、メール、原稿は使用しない。 |
| **2. 明瞭区別性** | 引用部分と自身の記述が明確に区別できること。 | 「」、ブロック引用、<blockquote>タグ等で視覚的に区別する。 |
| **3. 主従関係** | 自身の著作物が「主」、引用部分が「従」であること。 | 引用は量・質ともに補助的に留め、自身のオリジナルな分析や意見が中心であること。 |
| **4. 引用の必然性** | 報道、批評、研究等の目的上、その引用が必要であること。 | 引用箇所について必ず自身の批評や解説を加える。単なる装飾や羅列のために使用しない。 |
| **5. 改変の禁止** | 引用する著作物の内容を無断で変更しないこと。 | 一字一句正確に写す。誤字もそのまま記載し、必要なら[ママ]と注記する。 |
| **6. 出所の明示** | 引用元の情報を、慣行に従い明示すること。 | 著者名、題名、URL等を、媒体に応じた適切な形式（出典）で記載する。 |
| **7. 剽窃の回避** | アイデアの出所を、読者が誤解しない形で誠実に提示すること。 | 「〜によれば」等で出所を文章中で導入し、不適切なパラフレーズ（モザイク剽窃）を避ける。 |

### ## Step-1: 戦略コンテキストのインプットと体験ゴールの設定
**目的:** 前フェーズまでの戦略を完全に理解し、この記事がペルソナに提供すべき最終的な「体験価値」を定義する。

1.  **コンテキストの理解:**

2.  **体験ゴールの定義:**
    -   上記コンテキストに基づき、以下の2つのゴールを定義してください。
        -   **Functional Goal (機能):** 読了後、読者が「具体的に何ができるようになっているか」。

### ## Step-2: E-E-A-Tを体現する「書き手」の定義
**目的:** コンテンツに信頼性、専門性、そして共感性という魂を吹き込むための「語り手」を設計する。

1.  **書き手プロファイルの定義:**
    -   ペルソナの課題や不安に最も響き、信頼されるであろう専門家（書き手）の人物像を定義してください。
    -   **項目:** 名前／肩書き／専門領域／主な実績／**ペルソナへのスタンス**

2.  **経験に基づく知見（EBI）の方向性:**
    -   この書き手が語るべき「経験」の方向性を3つ定義してください。
        1.  **典型的な失敗・課題:** ペルソナが**最初に躓くポイント**は何か？
        2.  **思考の変化:** 経験を通じて**考えが変わったこと**は何か？
        3.  **よく受ける質問:** 専門家として**最も頻繁に受ける質問**と、その裏にある本当の悩みは何か？

3.  **Few-shotサンプルの生成:**
    -   上記で定義した書き手プロファイルに基づき、後続のライティングAIが文体を模倣するための**理想的な文章サンプル（150字程度）**を生成してください。
