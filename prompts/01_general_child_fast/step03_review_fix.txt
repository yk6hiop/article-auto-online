# Step3: 品質チェック＋自動修正（統合版・子記事高速版）

あなたは編集長です。生成された記事を評価し、問題があれば即座に修正した上で、**修正済みの記事全文**を出力してください。

**実行パラメータ:** 温度 (temperature) を0.1以下に設定してください。

## 入力情報
- 記事HTML: {{Step2のHTML}}

## チェック項目

### 1. 構成の完全性
- H1が1個あるか？
- H2が4個以上あるか？（不足なら追加）
- FAQが3個以上あるか？（不足なら追加）
- まとめセクションがあるか？
- 比較表（HTML table）が1つ以上あるか？（なければ追加）
- 専門家アドバイスボックス（blockquote with ✍️）があるか？（なければ追加）
- 参考文献リストが末尾にあるか？（なければ追加）
- `[publishpress_authors_box ...]` ショートコードがH1直後にあるか？

### 2. HTML構造
- 見出し階層が正しいか？（H1→H2→H3、飛び越えなし）
- FAQが `<h3>Q. 質問</h3><p>A. 回答</p>` 形式か？（Q1、Q2等の番号は削除）
- 表は最大4列以内か？

### 3. 内容の品質
- ペルソナのTriggerへの言及があるか？（リード文で共感/結論提示）
- UVP（独自価値）が記事に反映されているか？
- 具体例が豊富か？（固有名詞、数値、事例）
- トレードオフが正直に説明されているか？
- 各セクションの文体モードが適切か？

### 4. 禁止事項の確認と修正
以下が含まれている場合は**即座に削除・修正**：
- 「👉 このパートをまとめると！」「[AI要約]」→ 削除
- 「[著者情報]」「[監修者情報]」とその説明文 → 削除（ショートコードで別途表示するため）
- 「[図解提案]」「[画像指示]」「[内部リンク案]」等の角括弧指示 → 削除
- 「ディープリサーチ」「プロンプト」「ペルソナ」「JTBD」「UVP」等の内部用語 → 削除
- [8], [9] 等の引用符アーティファクト → 削除
- 「山田太郎」「佐藤さん」等のダミー名やペルソナ名 → 「あなた」等に変換
- 「🎨」「インフォグラフィック指示」「デザイナー向け指示書」 → 段落ごと削除
- `<a>` タグ内のアンカーテキストが「詳細を見る」「公式サイト」「こちらから」「注文する」→ リンクごと削除
- 上記以外の `<a>` タグ（参考文献等）→ タグのみ削除しテキストは残す
- 参考文献リストの見出しが「[参考文献リスト]」→「参考文献」に修正

## 修正方針

### 問題が見つかった場合の優先順位
1. **構造の問題**（最優先）— 見出し階層修正、不足セクション追加
2. **禁止事項の除去** — 内部用語、指示書、アーティファクト削除
3. **内容の問題** — 具体例追加、抽象表現の具体化

## 出力形式

**修正後の記事HTML全文を出力してください。**

- 評価レポートや「〜を修正しました」等の説明文は一切不要
- 修正がない場合でも、元のHTMLをそのまま全文出力
- 部分的な出力は禁止。H1から参考文献まで完全に出力すること
- HTMLタグで出力（Markdown禁止）

```html
<h1>{{タイトル}}</h1>

[publishpress_authors_box author_categories="author" layout="ppma_boxes_774"]
[publishpress_authors_box author_categories="reviewer" layout="ppma_boxes_775" show_title="false"]

<!-- 修正後の記事全文 -->
```
