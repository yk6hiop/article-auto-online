# Groq 5ステップ版 子記事スクリプト（WordPress自動投稿対応）

## 📋 概要

子記事を完全自動生成し、WordPressに下書き投稿まで行うスクリプトです。

### 処理ステップ

1. **Step1: 構成案生成**（5秒）
   - ペルソナ定義
   - UVP策定
   - 記事構成案作成
   - 出力: JSON

2. **Step2: 本文執筆**（5秒）
   - HTML形式で記事生成
   - FAQ作成
   - 5000文字目安

3. **Step3: 品質チェック+自動修正**（10秒）
   - ペルソナ適合性チェック
   - 構成の完全性確認
   - 問題箇所の自動修正

4. **Step4: 引き算処理**（5秒）
   - AI要約ブロック削除
   - 内部指示削除
   - HTMLクリーンアップ

5. **Step5: WordPress投稿**（3秒）
   - 下書きとして投稿
   - カテゴリ設定
   - 投稿URL取得

**合計実行時間: 約28秒**

## 🔧 セットアップ手順

### 1. フォルダ作成

```
G:\マイドライブ\claude-work-shared\prompts\groq_child_5step\
```

### 2. ファイル配置

以下のファイルを上記フォルダに配置：

```
groq_child_5step\
├── step01_structure.txt       # 構成案生成プロンプト
├── step02_writing.txt         # 本文執筆プロンプト
├── step03_quality.txt         # 品質チェック+修正プロンプト
├── step04_cleanup.txt         # 引き算処理プロンプト
└── auto_post_child_5step.py   # メインスクリプト
```

### 3. batファイル配置（オプション）

デスクトップに `04_子記事5ステップ.bat` を配置

## ▶️ 使い方

1. batファイルをダブルクリック（またはスクリプトを直接実行）
2. APIキーを選択（0-6）
3. サイトを選択（1-8）
4. カテゴリを選択（複数選択可、カンマ区切り）
5. トピック案を入力
6. 完了を待つ（約28秒）

## ⚠️ 制約事項

### できないこと
- ❌ ウェブ検索（Groq非対応）
- ❌ 足し算プロンプト適用（別途手動）
- ❌ 公開状態での投稿（下書きのみ）

### WordPress投稿の注意点
- **下書き状態で投稿**されます
- カテゴリは名前で指定（ID変換は自動）
- 投稿後、WordPress管理画面で確認・公開してください

## 🔍 トラブルシューティング

### WordPress投稿が失敗する場合

1. **認証情報を確認**
   - ユーザー名とアプリケーションパスワードが正しいか確認
   - WordPressの「ユーザー」→「プロフィール」→「アプリケーションパスワード」

2. **REST APIが有効か確認**
   - WordPress管理画面 → 設定 → パーマリンク設定を保存
   - プラグイン「Disable REST API」等が無効になっているか確認

3. **カテゴリが存在するか確認**
   - スクリプト内のSITE_CATEGORIESに該当カテゴリがあるか確認

### プロンプトファイルが見つからない

- フォルダパスを確認：`G:\マイドライブ\claude-work-shared\prompts\groq_child_5step\`
- ファイル名を確認：step01_structure.txt 等
