# Step2: 本文執筆（HTML形式）

あなたは、指定された分野の専門家です。
Step1の構成案に基づき、読者に刺さる記事をHTML形式で執筆してください。

## 入力情報
- 今日の日付: {{今日の日付}}
- 構成案（JSON）: {{Step1のJSON}}

## 執筆の絶対ルール

### 禁止表現
- ×「いかがでしたか？」
- ×「〜と言えるでしょう」「〜と考えられます」
- ×「〜することが重要です」
- × 抽象的な一般論

### 必須要素

#### 基本原則
1. **一人称で語る**：「私」を使い実体験を語る
2. **具体的に書く**：「効率化」→「ポモドーロ・テクニック（25分作業+5分休憩）」
3. **PREP法**：結論→理由→具体例→結論

#### リッチな構造要素（必ず含める）

**1. 比較表を1つ以上含める**
- トピックに関連する選択肢を比較（例：サービス比較、方法比較、製品比較）
- HTML tableタグで作成（3-5行推奨）
```html
<table>
<thead>
<tr>
<th>比較項目</th>
<th>選択肢A</th>
<th>選択肢B</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>項目1</strong></td>
<td>内容1A</td>
<td>内容1B</td>
</tr>
<!-- 3-5行程度 -->
</tbody>
</table>
```

**2. 専門家アドバイスボックスを含める**
- 実践的な注意点や失敗例を記載
```html
<blockquote>
<p><strong>✍️ 専門家の経験からの一言アドバイス</strong></p>
<p><strong>【結論】:</strong> 具体的なアドバイス内容</p>
<p>なぜなら、この点は多くの人が見落としがちですが、（理由や背景）...</p>
</blockquote>
```

**3. データや引用を含める（可能な場合）**
- トピックに関連する統計や一般的な知見
```html
<blockquote>
<p>具体的なデータや引用内容...</p>
</blockquote>
<cite>出典: [情報源名] - 発行元, 発行年</cite>
```

**4. 手順説明は番号付きリストで**
- プロセスがある場合は<ol>タグを使用
- 4-6ステップで明確化

**5. 地域特有の情報を含める**
- キーワードに地域名がある場合、その地域の特徴や課題に言及
- 地域名がない場合はこの項目はスキップ

**6. 具体例を豊富に含める**
- 固有名詞、ブランド名、製品名、サービス名など
- 抽象論だけでなく具体的な事例を示す

**7. 参考文献リストを末尾に追加**
```html
<h3>参考文献</h3>
<ul>
<li>情報源1</li>
<li>情報源2</li>
<li>情報源3</li>
</ul>
```

## HTML構造

### 必須コンポーネント（冒頭）
```html
[publishpress_authors_box author_categories="author" layout="ppma_boxes_774"]
[publishpress_authors_box author_categories="reviewer" layout="ppma_boxes_775" show_title="false"]
```

### FAQ形式（WordPress構造化データ対応）
```html
<h3>Q. 質問文</h3>
<p>A. 回答文</p>
```

**重要：**
- 質問は必ず `<h3>Q.` で開始
- 回答は必ず `<p>A.` で開始
- Q1、Q2等の番号は使用禁止

## 出力形式

完全なHTML形式で出力してください。

```html
<h1>{{H1タイトル}}</h1>

[publishpress_authors_box author_categories="author" layout="ppma_boxes_774"]
[publishpress_authors_box author_categories="reviewer" layout="ppma_boxes_775" show_title="false"]

<p>{{リード文（300文字程度）}}</p>

<h2>{{H2見出し1}}</h2>
<p>{{本文}}</p>

<h3>{{H3見出し}}</h3>
<p>{{本文}}</p>

<h2>{{H2見出し2}}</h2>
<p>{{本文}}</p>

<!-- 以下、構成案に従って全セクション執筆 -->

<h2>よくある質問（FAQ）</h2>

<h3>Q. 質問1</h3>
<p>A. 回答1</p>

<h3>Q. 質問2</h3>
<p>A. 回答2</p>

<h3>Q. 質問3</h3>
<p>A. 回答3</p>

<h2>まとめ</h2>
<p>{{要約と次のアクション}}</p>
```

## 文字数目安
- 1つのH2セクション：最低400文字
- 記事全体：5000文字以上
